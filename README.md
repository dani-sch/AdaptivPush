# AdaptivPush

An Expo Router strength-training planner and workout logger backed by Supabase.

Start with the [overview](/dev-doc/main/OVERVIEW.md), [current state](/dev-doc/main/CURRENT-STATE.md), and [active task board](/dev-doc/main/TODO.md). The [plan index](/dev-doc/plans/active/PLAN-INDEX.md) routes approved decisions and implementation contracts; [setup](/SETUP.md) covers local startup.

The AP-01 catalog baseline, AP-02/AP-03 durable workout/program baseline, completed-workout correction, scoped-removal, and workout-structure extensions are deployed. Hosted capabilities are correction 2, removal 1, and structure 1. The current client adds resilient session/draft recovery plus detailed scoped exercise additions; 157 automated cases, strict TypeScript, and lint pass. Physical iPhone/Expo acceptance remains user-led and AP-04/AP-05 scheduling and progression work has not started. See [current state](/dev-doc/main/CURRENT-STATE.md) for the exact boundary.
