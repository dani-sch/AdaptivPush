## Earlier September 15 scoped swap and correction foundation

Commit `e8163b9` supplies the locally verified scoped-swap/correction base. Follow-up commits `8fff2b2`, `ae56b7f` and `eaca4f6` make an owner/program/stable-day-matched active draft the shared effective-current-workout authority on Home, route Continue Workout to the exact draft, add an accessible expandable Home list, virtualize and memoize swap options, prefetch optional history outside Apply, gate duplicate taps, and move wider synchronization outside the immediate visual-response path. Logged sets keep their actual exercise/load identity; only unlogged sets move and optional replacement-compatible history may supply a load suggestion if it is already available.

Swap recovery is owner/draft/pending-operation scoped. No-later-workouts is a deterministic successful current-workout outcome and leaves no Retry panel. Genuine response loss retains the exact request; a later workout-only selection wins immediately, then safely reconciles and compensates only if the older wider request is confirmed. User copy is limited to the visible outcome, while diagnostic detail stays internal. Finalized durable sessions expose Edit workout from the completion/history surfaces. Corrections can change performed exercise, load/unit, reps, RPE and set membership; the local outbox reuses the exact operation after response loss, while `correct_completed_workout_v1` checks owner and expected correction revision, atomically replaces effective sets, updates completion/volume/correction-aware records, writes an internal before/after audit and returns one replayable receipt. It does not reopen finalization, create another session, reactivate an archived/ended program or replay advancement.

At the September 15 checkpoint the additive correction migration had only local verification.
