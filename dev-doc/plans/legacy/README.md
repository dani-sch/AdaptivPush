# Historical planning archive

This directory preserves executed or superseded plans intact. Archived content is historical and non-authoritative even when its old text claims active status. Archival does not imply the plan was implemented.

The [2026-09-08 supersession archive](/dev-doc/plans/legacy/2026-09-08-superseded/README.md) preserves prior authorities and operational snapshots. Its [inventory/map](/dev-doc/plans/active/ADAPTIVPUSH-DOCUMENT-INVENTORY.md) records original paths, replacements, retained value and byte hashes. Use the [current plan index](/dev-doc/plans/active/PLAN-INDEX.md) for current authority. Research, audits, original requests and logs remain discoverable at their retained evidence paths.
